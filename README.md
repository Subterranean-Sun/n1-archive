# N1 历年研习室 · 原始资料与答案归档

为 https://Subterranean-Sun.github.io/n1-study/ 保存 2010—2026 年的原始资料和答案原件。

[v2026-11-19](https://github.com/Subterranean-Sun/n1-archive/releases/tag/v2026-11-19) 提供：

- original-materials-2010-2026.zip：原始资料，共 98 个文件。
- original-answers-2010-2026.zip：答案原件，共 64 个文件。
- manifest.json：逐文件大小、SHA256、CRC32 和归档校验信息。

ZIP 解压后保留原文件夹和内部层级。同类整包下载一次即可。日常做题的 PDF 和题图由主站直接提供。

[snapshot-2026-11-19](https://github.com/Subterranean-Sun/n1-archive/releases/tag/snapshot-2026-11-19) 保存站点、听力与原件包的完整分片快照及 SHA256，供自动部署和恢复使用。原件发布工作流会先校验分片、重组 ZIP，再校验整包后发布正式归档。本仓库无须开启 Pages。
